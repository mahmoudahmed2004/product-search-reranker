# Storefront V3 plan

- Regenerate the pinned sample catalog with unrelated departments and a narrow product-kind taxonomy. Preserve device-fit rules and add reviewed sport and kitchen pairings.
- Use the latest search and an optional last-viewed product as homepage inputs. Require retrieval evidence before displaying a topic. Reuse dense and sparse retrieval and keep recommendations in the selected department. Keep the browser context for one day, with a clear control.
- Present the current topic before the general catalog. Keep cold-start browsing useful with links to unrelated departments, a limited first grid, and progressive browsing. Verify returning home, changing search topics, clearing context, and loading product pages.
- Measure topic coverage, cross-department drift, and abstention on fixed examples. Compare the homepage recommendations with raw hybrid top results and keep the supervised ESCI metrics separate.
